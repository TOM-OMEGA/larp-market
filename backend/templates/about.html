// 我們是誰

LARP 二手市集是專為台灣 LARP 玩家成立的道具交易平台。大眾化，不限定團體，歡迎所有玩家加入。

// 交易流程

① 買家下訂金（50%），留在平台帳戶
② 賣家寄出，湯姆轉一半費用給賣家
③ 湯姆確認收到沒問題，轉尾款
④ 每週三林森公園夜貓聚會面交

平台收取售價 10% 作為手續費。

// 面交地點

每週三晚上，林森公園（台北市中山區）。夜貓聚會固定舉行，歡迎帶武器來交流。

// 海外商品

我們也轉載大陸/日本等海外的二手盔甲。標示「海外」的商品預計等待 2–4 週，屆時會發送通知。寄丟了可向原平台申訴退款。

// 免責聲明

• 商品資訊由賣家提供，平台僅提供上架空間
• 寄送損壞為物流責任，平台協助聯繫，不直接賠償
• 上架請附真實姓名電話以便聯繫
• 所有交易爭議由買賣雙方自行負責
